## Publicar en GitHub Pages

1. Mantén `index.html`, `style.css` y `script.js` en la raíz del repositorio.
2. Conserva tu carpeta `assets/` original con la fotografía y documentos.
3. Añade los archivos de la demo dentro de `assets/`.
4. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

> Nota: el vídeo MP4 de la demo es grande. GitHub limita los archivos individuales a 100 MiB en repositorios normales. Para publicar la demo en GitHub Pages, es preferible alojar el vídeo externamente (por ejemplo, YouTube no listado) y cambiar el enlace de la tarjeta por esa URL.
